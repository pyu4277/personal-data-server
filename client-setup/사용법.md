**드라이브 문자로 연결**해 일반 드라이브처럼 쓰게 만드는 설치 도구입니다.

## 설치

이 폴더의 **`개인서버 연결하기.bat`** 을 **더블클릭**하세요.

- 관리자 권한은 알아서 올라갑니다. UAC 창이 뜨면 **[예]**
- 비밀번호를 한 번 물어봅니다. 그 뒤로는 다시 묻지 않습니다
- 끝나면 `내 PC` 에 **`개인서버 (S:)`** 가 생깁니다

드라이브 문자는 비어 있는 것을 자동으로 고릅니다. `S:` 가 쓰이고 있으면 `T:`, `U:` … 순으로 넘어갑니다.

### 다른 문자나 이름을 쓰고 싶으면

관리자 PowerShell에서:

```powershell
powershell -ExecutionPolicy Bypass -File ".\Connect-PersonalServer.ps1" -DriveLetter Z -Label "내서버"
```

## 연결 해제

**`개인서버 연결끊기.bat`** 더블클릭.

드라이브 연결, 저장된 비밀번호, 표시 이름 설정, 자동 재연결 작업을 전부 지웁니다.
**로컬 드라이브(C:, D: 등)는 절대 건드리지 않습니다.**

---

## 자주 나오는 상황

### 재부팅 후 드라이브에 빨간 X 가 보인다
부팅 직후에는 네트워크와 Tailscale이 아직 안 올라와서 그렇습니다.
설치 시 등록된 **로그온 재연결 작업**이 1분 뒤 자동으로 다시 붙입니다. 잠시 기다리세요.

### 관리자 권한으로 실행한 프로그램에서 드라이브가 안 보인다
Windows의 UAC 토큰 분리 때문입니다. 설치 시 `EnableLinkedConnections` 를 켜두었고,
**재부팅 한 번**이면 해결됩니다.

### "액세스가 거부되었습니다"
비밀번호가 틀렸을 가능성이 큽니다. `연결끊기` 후 다시 `연결하기` 를 실행하세요.

### 서버 PC 본인에서 실행하면
"이 PC 가 서버 본인입니다" 라고 알리고 아무것도 하지 않습니다.
서버에서는 `D:` 를 직접 쓰면 됩니다.

### 아이콘이 네트워크 드라이브 모양 그대로다
표시 이름은 바뀌지만 아이콘은 Windows가 매핑 드라이브에 대해 무시하는 경우가 많습니다.
기능에는 영향 없습니다.

### `내 PC` 에서 "네트워크 위치" 구역에 뜬다
Windows는 매핑된 네트워크 드라이브를 **항상** 이 구역에 넣습니다.
"장치 및 드라이브" 로 옮기는 설정은 존재하지 않습니다.

이전 버전에서 발견해 수정한 결함:

- 드라이브 문자 충돌 미검출 (오류 85)
- 같은 서버 중복 연결 (오류 1219)
- PowerShell 5.1 에서 네이티브 exe 에 `2>&1` 사용 시 정상 stderr 가 종료 오류로 승격

- 매핑된 네트워크 드라이브 이름은 `MountPoints2\_LabelFromReg` 로만 바뀜
- 한글 포함 `.ps1` 은 **BOM 있는 UTF-8** 로 저장해야 PowerShell 5.1 이 올바로 파싱
